XÂY DỰNG WEB APP BẰNG GOOGLE APPS SCRIPT – TỪNG BƯỚC

Sản phẩm của mỗi nhóm: một web app gồm biểu mẫu (Index.html) → tính toán liên môn (JavaScript) → lưu Google Sheet (Code.gs) → thống kê từ dữ liệu đã lưu. Mã minh họa dưới đây là ví dụ chung; nhóm tự viết mã cho đề tài của mình.

Bước: 012345678

0 Chuẩn bị

  • Trưởng nhóm tạo một Google Sheet đặt tên STEM – Nhóm … – tên web app, chia sẻ quyền Người chỉnh sửa cho các bạn trong nhóm và giáo viên.
  • Trong Sheet: Tiện ích mở rộng → Apps Script. Đổi tên dự án (góc trên bên trái) trùng tên Sheet. Dự án gắn với Sheet nên SpreadsheetApp.getActiveSpreadsheet() chính là Sheet của nhóm.
  • Phân công: Lập trình máy chủ viết Code.gs, Lập trình giao diện viết Index.html, Thiết kế ghi tên các cột của Sheet, Chuyên gia liên môn chuẩn bị công thức và bộ số liệu tính tay để kiểm thử.

1 Web app đầu tiên: “Xin chào”

Trong Code.gs, xóa hàm mẫu, viết hàm doGet – hàm chạy khi có người mở đường liên kết của web app:

function doGet() {
  return HtmlService.createHtmlOutputFromFile("Index")   // tên tệp HTML, không có đuôi .html
    .setTitle("Tên web app của nhóm")
    .addMetaTag("viewport", "width=device-width, initial-scale=1");  // hiển thị đẹp trên điện thoại
}

Bấm + → HTML, đặt tên tệp Index, gõ thử:

<!DOCTYPE html>
<html lang="vi">
<head><base target="_top"><meta charset="UTF-8"></head>
<body>
  <h2>Xin chào, đây là web app của Nhóm …</h2>
</body>
</html>

Triển khai → Tùy chọn triển khai mới → biểu tượng ⚙ → Ứng dụng web. Thực thi với tư cách: Tôi; Người có quyền truy cập: Bất kì ai (hoặc chỉ người trong trường). Bấm Triển khai, tự cấp quyền bằng tài khoản của mình, rồi mở URL ứng dụng web (kết thúc bằng /exec) trên điện thoại.

2 Biểu mẫu nhập liệu (Bài 12) trong Index.html

Thay nội dung <body> bằng biểu mẫu của nhóm, dùng đúng kiểu ô nhập đã học: text, number (có min, max, step), date, time, radio/checkbox cùng name, select, fieldset + legend. Mỗi ô cần id để JavaScript đọc được.

<form id="f">
  <fieldset>
    <legend>Thông tin chung</legend>
    <label>Lớp: <select id="lop"><option>12A8</option><option>12A1</option></select></label>
    <label>Số lượng: <input type="number" id="soLuong" min="0" step="1" value="1"></label>
  </fieldset>
  <div id="kq"></div>
  <button type="submit">Lưu</button> <span id="tb"></span>
</form>

Phiên bản 1 của nhóm là biểu mẫu đầu tiên này; cả lớp cùng tìm lỗi (sai kiểu ô, thiếu ô, radio khác name…) để sửa thành phiên bản 2.

3 Tính toán theo công thức liên môn bằng JavaScript

Đặt <script> ở cuối <body>. Đọc giá trị, áp dụng công thức nhóm đã kiểm chứng bằng tính tay, hiện kết quả và cách thay số:

<script>
  const $ = id => document.getElementById(id);
  const so = id => Number($(id).value) || 0;        // ô trống → 0

  function tinh() {
    const a = so("soLuong"), b = 150;                 // ví dụ: công suất 150 W mỗi thiết bị
    const P = a * b;                                  // công thức liên môn của nhóm
    $("kq").innerHTML = "P = " + a + " × " + b + " = <b>" + P + " W</b>";
  }
  $("f").addEventListener("input", tinh);            // tính lại mỗi khi nhập
  tinh();
</script>

Chuyên gia liên môn so kết quả trên màn hình với tính tay ở ít nhất 3 bộ số liệu. Chỗ nào lệch: kiểm tra đơn vị (W/kW, g/100 g, giờ/phút) và thứ tự phép tính.

4 Lưu dữ liệu vào Google Sheet

Trong Code.gs, viết hàm nhận dữ liệu từ trang web và ghi thành một dòng. Tên cột theo bản thiết kế của nhóm.

const TEN_SHEET = "DuLieu";
const COT = ["Thời gian", "Lớp", "Số lượng", "Kết quả"];

function laySheet_() {                               // dấu _ ở cuối: hàm nội bộ, trang web không gọi được
  const ss = SpreadsheetApp.getActiveSpreadsheet();
  let sh = ss.getSheetByName(TEN_SHEET);
  if (!sh) { sh = ss.insertSheet(TEN_SHEET); sh.appendRow(COT); sh.setFrozenRows(1); }
  return sh;
}

function luuPhieu(dl) {                               // dl là đối tượng do trang web gửi lên
  if (!dl.lop) throw new Error("Thiếu lớp");          // kiểm tra dữ liệu ở máy chủ
  const kq = dl.soLuong * 150;                        // tính lại ở máy chủ để Sheet luôn đúng
  laySheet_().appendRow([new Date(), dl.lop, dl.soLuong, kq]);
  return "Đã lưu";
}

Trong Index.html, khi bấm nút: chặn trang tải lại, gom dữ liệu thành đối tượng, gọi hàm máy chủ bằng google.script.run:

$("f").addEventListener("submit", e => {
  e.preventDefault();                                 // không có dòng này trang sẽ trắng
  const dl = { lop: $("lop").value, soLuong: so("soLuong") };
  $("tb").textContent = "Đang lưu…";
  google.script.run
    .withSuccessHandler(tl => $("tb").textContent = "✔ " + tl)
    .withFailureHandler(err => $("tb").textContent = "Lỗi: " + err.message)
    .luuPhieu(dl);
});

Phiên bản 2 hoàn chỉnh khi mỗi lần gửi tạo đúng một dòng, đủ cột trong Sheet.

5 Đọc lại dữ liệu và thống kê

Viết hàm đọc toàn bộ Sheet, tính số liệu thống kê (số trung bình, tần số, tần số tương đối, xếp hạng…) và trả về cho trang web:

function layThongKe() {
  const v = laySheet_().getDataRange().getValues().slice(1);    // bỏ dòng tiêu đề
  const N = v.length;
  const tb = N ? v.reduce((t, r) => t + Number(r[3]), 0) / N : 0;
  return { N: N, trungBinh: Math.round(tb * 100) / 100 };         // KHÔNG trả về kiểu Date
}
function hienThongKe(t) {
  $("tk").innerHTML = "Đã có " + t.N + " phiếu, trung bình " + t.trungBinh;
}
google.script.run.withSuccessHandler(hienThongKe).layThongKe();  // chạy khi mở trang

Thêm <div id="tk"></div> vào trang. Sau khi lưu, cho luuPhieu trả về layThongKe() để bảng cập nhật ngay. Thời gian lấy từ Sheet phải đổi sang chữ: Utilities.formatDate(d, "Asia/Ho_Chi_Minh", "dd/MM/yyyy").

6 Cập nhật web app sau mỗi lần sửa

Đường liên kết /exec chỉ chạy phiên bản đã triển khai. Khi sửa mã: Triển khai → Quản lý tùy chọn triển khai → ✏ Chỉnh sửa → Phiên bản: Phiên bản mới → Triển khai. Đường liên kết giữ nguyên. Trong lúc thử có thể dùng Triển khai → Kiểm thử các bản triển khai (đường liên kết /dev, luôn chạy mã mới nhất, chỉ người chỉnh sửa mở được).

8 Kiểm thử bằng số liệu đo thật và cải tiến (phiên bản 3)

  1. Nhập lần lượt các bộ số liệu nhóm đã đo (nhãn thiết bị, nhãn dinh dưỡng, sổ mượn, nhật kí giấc ngủ).
  2. Ghi vào bảng kiểm thử: dữ liệu nhập – kết quả web app – kết quả tính tay – đạt/chưa đạt.
  3. Thử cả dữ liệu “khó”: ô trống, số âm, ngày cuối tháng, qua nửa đêm, chọn nhiều mục.
  4. Mở Sheet kiểm tra mỗi lần gửi đúng 1 dòng, đủ cột; bảng thống kê trên trang trùng với đếm tay.
  5. Sửa lỗi, thêm chức năng mở rộng → phiên bản 3; ghi lại mỗi thay đổi vào nhật kí nhóm.

Lưu ý an toàn dữ liệu: không thu thập họ tên đầy đủ, số điện thoại, địa chỉ; khảo sát sức khỏe phải ẩn danh. Không dán khóa API hay mật khẩu vào mã nguồn.
